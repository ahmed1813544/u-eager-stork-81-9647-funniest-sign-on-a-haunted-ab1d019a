Entry for the [make.fun bounty "Funniest Sign on a Haunted Server Room Door"](https://make.fun/bounty/u-eager-stork-81-9647-funniest-sign-on-a-haunted-ab1d019a).

`main.py` (Python standard library only, deterministic) writes one funny
sign line to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`,
or `/output` by default).

The sign:

> SERVER ROOM: IF YOU HEAR TYPING AND NO ONE IS HERE, IT'S DAVE. HE NEVER LOGGED OUT.

## Run

```sh
python3 main.py
```
